# EdenText

EdenText is a full-featured word processor that runs entirely in your browser. It opens and saves ODT and DOCX files, exports PDFs, and includes editing, review, and spell-checking tools.

Try the [EdenText demo](https://edentext.app/).

## Privacy and storage

Documents are processed and stored in your browser; the EdenText container does not store them. Browser storage is tied to the browser profile, so keep separate backups of documents you want to preserve. EdenText is in beta, so keep backups of important work.

Use HTTPS to enable EdenText's offline and installable-app features.

See the [EdenText repository](https://github.com/stffnb/edentext) for release notes and more information.
